## 3. リリースノート (Changelog - v3.7.0)

### 🌟 新機能 & 仕様改善 (New Features & UX Improvements)
1. **デッキ未選択キャラクターの所持図鑑ランダム自動選抜システム**:
   - メインキャラ、サブ1、サブ2のいずれかがデッキで未選択（未セット）の場合でも、プレイヤーの所持図鑑（`collection`）の未選択キャラクターからランダムに自動選出してバトルに出撃するヘルパー（`getBattleReadyTeam`）を実装。
   - これにより、手動でデッキ編成を1体ずつ設定しなくても、スキャンしてモンスターがいれば即座に1P/3P対戦を楽しめるようになりました。
2. **対戦ロビー ホスト対戦モード完全同期 & 接続タイムアウト防止**:
   - ゲスト側がロビーで「1P対戦」「3P対戦」のどちらを選択していても、ホストが作成した部屋のルール（3P/1P）にゲストが自動で完全追従するよう改修。
   - モードの事前選択不一致による接続エラーを根絶し、接続タイムアウト時間を15秒に延長してP2P接続安定性を向上させました。
