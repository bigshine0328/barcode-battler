## 3. リリースノート (Changelog - v3.5.0)

### 🛠️ 不具合修正 & 機能改善 (Bug Fixes & Network Stability)
1. **レベル成長ステータスの全画面リアルタイム同期 (Hydration)**:
   - `StorageManager.getDeck()` において、各スロットに登録されたカードを図鑑（`collection`）の最新データと即座に突合・同期する処理を実装。
   - レベルアップ後のステータス（HP, ATK, DEF, SPD）が、ホーム画面（`SCR-01`）のメインキャラ展示およびバトル画面（`SCR-06`）の実際のHPゲージ・与被ダメージ計算に100%リアルタイムに反映されるようになりました。
2. **P2Pバトル中の切断・逃走時強制終了 & 対戦ロビー自動復帰**:
   - 対戦相手が「にげる」を押した際に `ESCAPE` メッセージを送信するよう改善。
   - Host/Guest双方のデータチャネルに `close` / `error` イベントリスナーを追加。
   - 相手の逃走・通信切断（ブラウザ終了・電波断絶）時に画面がフリーズせず、「相手との接続が切断されました」という通知後に安全に対戦ロビー（`SCR-05`）へ自動復帰するエラーハンドリングを実装。
