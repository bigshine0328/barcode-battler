## 3. リリースノート (Changelog - v3.6.0)

### 🛠️ 重大不具合修正 (Critical Bug Fixes)
1. **3P対戦 クライアント側サブキャラ「いあつのたて」化バグの根絶**:
   - ゲスト側がルーム参加（`JOIN`）時に常に3体チームを送信するよう改修。
   - キャラクター不足時のフォールバック生成でアイテムカードコード（いあつのたて）が使われていた問題を修正し、キャラクター型保証ヘルパー（`getFallbackCharacter`）を導入。
   - これにより、3P対戦時にクライアント側のサブ1・サブ2が意図せずアイテムカード化する現象を100%根絶しました。
2. **P2Pバトル中の逃走・切断時における双方向ロビー自動復帰の堅牢化**:
   - 「にげる」実行時に `ESCAPE` メッセージを確実に相手に届けるため、120ms のバッファ待機を入れてからコネクション切断を実行する安全フローを導入。
   - PeerJS の多重イベント（`close`/`error`/`disconnected`）による切断検知を強化し、逃げた本人および相手側の双方が確実にダイアログ表示と共に対戦ロビー（`SCR-05`）へ自動復帰することを保証しました。
