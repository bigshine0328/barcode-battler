## 1. デザインシステム & カラーパレット (Cyber Arctic Arcade)

### 属性別マルチカラー
- **🔥 火 (Fire)**: メイン `#ff2200` / サブ `#ffd700` / 瞳 `#ffff00`
- **💧 水 (Water)**: メイン `#0088ff` / サブ `#e0ffff` / 瞳 `#00ffff`
- **🌲 木 (Wood)**: メイン `#00aa44` / サブ `#aaffaa` / 瞳 `#ffff33`

### レアリティ別ボーダー（常時維持）
- **✨ SSR**: 2px ゴールドボーダー (`#ffd700`) ＋ 16芒サンバースト背景
- **🌟 SR**: 2px パープルボーダー (`#b066ff`) ＋ サイバーヘックス背景
- **🔷 R**: 2px シアンボーダー (`#00e5ff`) ＋ クリスタルリング背景
- **⚪ N**: 1.5px スレートボーダー (`#3e4868`) ＋ サークルベース背景

### デッキセット中の視覚表現（案A）
- **外枠ボーダー色の上書きを廃止**: レアリティ本来の枠線色（SSRの金、SRの紫、Rの水色、Nの灰色）が100%保持される。
- **カード内側インナーグロー**: 鮮やかなシアンのグラデーション発光（`inset 0 0 12px rgba(0, 229, 255, 0.5)`）。
- **左上インジケーター**: `<span class="deck-ribbon">✅ DECK</span>`
- **右上役職バッジ**: `<span class="slot-badge">⚔️ メイン / 💊 アイテム1 等</span>`（カード内側右上隅に完全格納され、横見切れ・横スクロールをゼロ化）。

### 図鑑カード内テキスト・ステータスの全視認性仕様 (v2.4.2)
- **キャラクター名**:
  - `white-space: nowrap` による過度な省略（`...`）を廃止。
  - `.card-name-box` による自然な2行折り返し（`word-break: break-word; line-height: 1.25;`）を実装し、長い名前（例: `[SSR] ばくえんのドラゴンバトラー`）も全文字確実に読める。
- **ステータス表示 (HP / ATK)**:
  - 属性タグ（`🔥火`）に加え、鮮やかな個別チップ（`.stat-chip-hp` : エメラルド発光, `.stat-chip-atk` : ローズ発光）で整理。
  - 数値が見切れることなくクリアに判別可能。
- **アイテム効果説明**:
  - `.stat-chip-item` により折り返しで全文表示。
