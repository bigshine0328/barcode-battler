## 1. デザインシステム & カラーパレット (Cyber Arctic Arcade)

### 属性別マルチカラー & エレメントドット
- **🔥 火 (Fire)**: メイン `#ff2200` / サブ `#ffd700` / 属性丸印 `#ff3344 ●`
- **💧 水 (Water)**: メイン `#0088ff` / サブ `#e0ffff` / 属性丸印 `#00e5ff ●`
- **🌲 木 (Wood)**: メイン `#00aa44` / サブ `#aaffaa` / 属性丸印 `#00ff88 ●`
- **💀 戦闘不能**: `#888888 💀`

### レアリティ別【発光オーラエフェクト】
- **✨ SSR**: 黄金の強烈な光輪オーラ (`box-shadow: 0 0 16px rgba(255, 215, 0, 0.75), inset 0 0 10px rgba(255, 215, 0, 0.3)`) ＋ 黄金放射グラデーション
- **🌟 SR**: 紫のミスティックオーラ (`box-shadow: 0 0 14px rgba(176, 102, 255, 0.65), inset 0 0 8px rgba(176, 102, 255, 0.25)`)
- **🔷 R**: 水色のサイバーオーラ (`box-shadow: 0 0 10px rgba(0, 229, 255, 0.5)`)
- **⚪ N**: シンプルシャドウ (`box-shadow: 0 2px 6px rgba(0, 0, 0, 0.4)`)

### デッキ選択中【外枠囲み】仕様
- **外枠をしっかり囲う**: `border: 2.5px solid var(--secondary-cyan) !important;`（鮮やかなシアンフレーム）。
- **左上タグ**: `<span class="deck-ribbon">✅ DECK</span>`
- **右上役職バッジ**: `<span class="slot-badge">⚔️ メイン / 💊 アイテム1 等</span>`

## 2. 画面レイアウト & コンポーネント (SCR-01 〜 SCR-07)

### 【SCR-04: 図鑑画面】
- 横スクロールなし・文字欠落なし・レアリティ発光とデッキ選択枠線が明快に分離された美しいカード一覧。
- 暗色バートレイ（`background: rgba(0, 0, 0, 0.7);`）内に能力値（HP/ATK/DEF/SPD）およびアイテム効果を常時視認表示。

### 【SCR-05: 対戦ロビー画面】
- 1P対戦（1体勝負） / 3P対戦（3体チーム戦）のルール切り替えトグル。
- 部屋作成時の4桁コード大文字表示（`#host-room-code`）。
- 参加時のゲスト入力欄（`#input-guest-code`）はロビー復帰時に自動空文字クリア。

### 【SCR-06: バトル画面 (ノースクロール完全対応)】
- **ビューポート内収容**: 縦スクロール・横スクロールが一切不要で、全デバイスの1画面内に美しく収まるレイアウト。
- **3Pチームサブカプセルスロット (`.team-sub-slots`)**:
  - 敵・味方それぞれのファイターバー直下に横並び3分割のスロットを配置。
  - 出撃中キャラは黄金枠ハイライト＋属性丸印（`●`）＋残りHP/最大HP＋ミニHPバー。
  - 控えキャラは通常枠＋属性丸印（`●`）＋残りHP/最大HP＋ミニHPバー。
  - 戦闘不能キャラはグレーアウト＋💀アイコン。
- **コマンドボタングリッド (`#battle-cmd-grid`)**:
  - 1P対戦時: 4ボタンレイアウト（`こうげき` `ひっさつ` `ガード` `アイテム`）
  - 3P対戦時: 5ボタン・2行レイアウト（上段: `こうげき` `ひっさつ` `ガード` / 下段: `アイテム` `こうたい`）
- **交代モーダル (`#battle-switch-modal`)**:
  - 生存している控えキャラの属性・HP一覧をポップアップ表示し、ワンタップで交代コマンドを決定。
