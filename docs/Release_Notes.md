## 1. バージョン別変更履歴 (Changelog)

### 🌟 v2.5.0 (2026-08-15) - P2Pホスト権威モデルによる完全同期 ＆ カメラ多重フォールバック堅牢起動

#### 🐛 重大不具合修正 & 通信同期エンジンの刷新 (Critical Fixes & Host Authority Sync)
1. **P2P対戦におけるHP/SPの完全同期保証（ホスト権威モデル）**:
   - **原因**: 双方の端末で独立してダメージ計算とターン処理が行われていたため、ランダム値やコマンド順の差異でHPがズレていました。
   - **対策**: **ホスト（Host）が一括してダメージ・アイテム効果・勝敗を計算し、確定ステート（`STATE_SYNC`）をゲストへ送信して100%同一の画面ステートを復元するアーキテクチャに刷新**。双方の画面でHP・SP・ログ・勝敗が1ミリもズレることなく完全一致します。
2. **バーコードスキャン画面でのカメラ起動不具合の解消**:
   - **原因**: 画面遷移時に自動起動フックが呼ばれていなかったこと、およびカメラ制約（OverconstrainedError）に対するフォールバックが不十分でした。
   - **対策**:
     - スキャン画面（`SCR-02`）遷移時の自動起動フックを復元。
     - 背面カメラ（`facingMode: ideal`） ➔ 標準カメラ ➔ 任意カメラの多重フォールバックチェーンを実装し、あらゆるAndroid/iOS/PCブラウザで確実にカメラが起動するよう堅牢化。

#### 🛡️ 品質 & テスト
- **自動単体テスト**: P2P完全同期テストを含む全35件 PASSED（100%合格）確認済み。
