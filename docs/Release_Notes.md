# 🚀 リリースノート (Release Notes v1.0.0)

## 1. アプリケーション概要

- **アプリ名**: バーコード対戦スマホアプリ（プロトタイプ版）
- **バージョン**: v1.0.0 (MVP Release)
- **対象環境**: モバイル (iOS / Android) / Web (Chrome, Safari, Edge)
- **起動方法**: ルートディレクトリの `index.html` をブラウザで開くか、ローカルWebサーバー（`npx serve .` 等）で起動。

---

## 2. 主な実装機能・ハイライト

1. **バーコードスキャン＆決定論的生成エンジン**
   - カメラおよびテストボタン/入力によるJAN13/8コード解析。
   - 同一バーコードから常に同じステータス（HP/ATK/DEF/SPD/属性/レアリティ/スキル）を決定論的に計算。
   - **称号1＋ベース名＋称号2** による4,000通りの名前生成と、ベースアセット×属性カラー×オーラによる動的グラフィック生成。
   - ガチャ風光カットイン演出。

2. **図鑑・所持カード管理**
   - 端末内ストレージ保存（最大100体保存制限、自動FIFO解放）。
   - 各カードへの自由記述 **「メモ欄（例: ポテトチップス）」** 編集機能。

3. **4桁ルームコード通信＆対戦ロビー**
   - 4桁の数字コード（例: 7821）による 0 円リアルタイムマッチング。
   - 1タップで動作確認が可能な **CPU対戦テストモード** を搭載。

4. **戦略的コマンドバトル**
   - **行動順判定**: $\text{SPD} \times \text{乱数}(0.85 \sim 1.15)$
   - **ダメージ計算**: $(\text{ATK} - \text{DEF}) \times \text{属性補正} \times \text{乱数}(0.9 \sim 1.1)$
   - **演出要素**: 8%の攻撃 MISS 判定、SPゲージ蓄積、必殺技発動、ガード（被ダメ50%カット）。
   - **切り札 (QTE)**: 1バトル1回発動可能なタイミング合わせミニゲーム（成功で2.5倍ダメージ）。

## 3. ファイル構成

- `index.html` (メイン画面)
- `src/css/style.css` (ネオンポップテーマスタイル)
- `src/js/barcode-engine.js` (バーコード解読・ステータス/名前/画像生成)
- `src/js/storage.js` (100体保存・メモ更新)
- `src/js/battle-engine.js` (ターン制バトル・ダメージ乱数・QTE)
- `src/js/network.js` (4桁ルームコード通信)
- `src/js/ui.js` (UI・画面遷移・QTEモーダル)
- `src/js/app.js` (アプリエントリーポイント)
- `tests/test-runner.html` & `tests/unit-tests.js` (単体テスト)
