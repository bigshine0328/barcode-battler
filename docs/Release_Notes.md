## 2. バージョン別変更履歴 (Changelog)

### 🌟 v2.3.0 (2026-08-15) - 20種族・新レアリティ確率・3アイテムスロット拡張

#### 🚀 新機能 (New Features)
1. **全20種族固有モンスター生成システム**:
   - 既存12種に加え、新たに8種族（`バトロボ`, `クラーケン`, `ペガサス`, `キマイラ`, `デーモン`, `レヴィアタン`, `ネクロマンサー`, `ファントム`）を追加。
   - 20種族すべてに固有の専用SVGベクターグラフィックを100%一致連動。
2. **新レアリティ確率分布の適用**:
   - **SSR: 3%** / **SR: 12%** / **R: 25%** / **N: 60%** の分布へ更新。
3. **デッキ3アイテムスロット編成 & 図鑑3枚同時ハイライト**:
   - デッキ編成に「強化アイテム1」「強化アイテム2」「強化アイテム3」の3スロットを新設。
   - 図鑑（ずかん）画面において、セットされた3種類のアイテムすべてに個別のバッジ（`[💊 アイテム1]`, `[💊 アイテム2]`, `[💊 アイテム3]`）が表示され、3枚ともハイライト枠線で表示。
4. **バトル中の3アイテム選択使用システム**:
   - バトル画面で「💊 アイテム」ボタンをタップした際、セットした3つのアイテム一覧から選択して発動できる専用モーダルを追加（各1回、合計3回まで使用可能）。

#### 🛡️ 改善 & 安定性向上 (Improvements)
- **カスケード保護**: 図鑑からアイテムカードを削除した際、セットされていた該当アイテムスロットのみを安全に自動解除する防御ロジックを強化。
- **キャッシュクリア設計**: モバイルブラウザでの即時反映のため、スクリプトおよびCSSに `?v=2.3.0` を適用。
