## 1. アプリケーション概要

本プロダクトは、身の回りの製品パッケージに印刷されたバーコード（JANコード/EAN-13等）をスマートフォンのカメラで読み取り、独自のアルゴリズムによって固有のモンスターキャラクターや強化アイテムを生成・収集・育成し、WebRTC P2P通信によるリアルタイムオンライン対戦およびCPU対戦を楽しめるリアルタイム対戦Webゲームです。

---

## 2. コア体験とターゲットユーザー

- **ターゲットユーザー**: 小中学生および昭和・平成のバーコードバトラーファン層。
- **コア体験**: 
  - 身の回りの製品（おかしの箱、ジュースの缶、ノート等）をスキャンして「激レアSSRモンスター」や「超強大アイテム」を発見する高揚感。
  - 自分だけのオリジナルデッキ（メイン1体・サブ2体・アイテム1種）を編成する戦略性。
  - ルームコード共有により、友達同士で1ポイントの狂いもなく完全同期する熱いリアルタイム対戦。

## 3. 主要機能要件一覧 (v2.1.0 仕様)

### 3.1 バーコードスキャン＆カード生成エンジン (`BarcodeEngine`)
1. **カメラリアルタイムスキャン**: `getUserMedia` によるデバイス背面カメラ起動と `BarcodeDetector` API によるJANコード自動読み取り。
2. **手動入力＆テストボタン**: カメラ非対応環境向けJANコード直接入力フォームおよびデモ用テストバーコード生成機能。
3. **12系統固有モンスター生成システム**:
   - JANコードのハッシュ値から、12種類の固有種族（`ドラゴン`, `ゴーレム`, `ナイト`, `フェニックス`, `タイガー`, `スライム`, `ベア`, `ロボ`, `ウルフ`, `ライオン`, `イエティ`, `グリフォン`）を厳密に生成。
   - キャラクター名（ベース種族名）とビジュアル（専用SVGグラフィック）が100%連動・一致。
4. **4段階レアリティ＆ステータス補正**:
   - **SSR (上位3%)**: 基礎ステータス **×1.60倍** (HP 1600~2400, ATK 250~380)
   - **SR (上位12%)**: 基礎ステータス **×1.35倍**
   - **R (上位35%)**: 基礎ステータス **×1.15倍**
   - **N (残り50%)**: 基礎ステータス **×1.00倍**
5. **アイテムカード生成＆4段階数値幅スケーリング**:
   - JANコードから全8種類の強化アイテムを生成。
   - アイテムにも4段階レアリティ（SSR 3%, SR 12%, R 35%, N 50%）を適用し、SSRアイテムは強力な倍率数値を発揮。

### 3.2 図鑑＆デッキ編成管理 (`StorageManager`)
1. **所持図鑑 (最大100枚)**: スキャンしたカードの閲覧、メモ編集（商品名等の記録）、パラメータ（HP/ATK/DEF/SPD）の確認。
2. **デッキセットスロット**:
   - **メインキャラ**: バトル出撃キャラクター
   - **サブキャラ 1 / 2**: 3Pチーム戦用出撃キャラクター
   - **強化アイテム**: バトル中に使用可能なアイテム
3. **自動データマイグレーション**: 過去バージョンで保存された図鑑データを最新のステータス計算式・画像描画エンジンへ即座に自動昇格。

### 3.3 対戦ロビー＆P2Pリアルタイム通信 (`NetworkManager`)
1. **PeerJS WebRTC P2P通信**: サーバーを介さず4桁のルームコードのみで端末同士を直接P2P接続。
2. **ホスト主導型確定ステータス全同期 (Authority-Client Pattern)**:
   - ホスト端末（部屋を作成した側）がターンのダメージ・ミス・HP・SP・勝敗を唯一の正解として一括計算。
   - ホストからゲストへ計算後の最新確定ステータス (`TURN_RESULT`) を一括送信するため、両スマホで表示される残りHP数値が100%完全一致。
3. **対戦モード**:
   - **1P対戦**: 1体勝負（最大10ターン）
   - **3P対戦**: 3体チーム戦（最大20ターン）
   - **CPU対戦テスト**: 毎回異なるランダムな敵と即座に対戦テストが可能。

### 3.4 バトルエンジン (`BattleEngine`)
1. **コマンド選択**:
   - **⚔️ こうげき**: 通常攻撃（毎ターン何度でも使用可能）。
   - **✨ ひっさつ**: SPゲージが 100% に到達したターンのみ発動可能（1.85倍超大ダメージ）。
   - **🛡️ ガード**: 被ダメージを半減し、SPゲージを +35% 蓄積。
   - **💊 アイテム**: **1バトル中に最大 3 回まで使用可能**（画面上で `(3/3)` からカウントダウン）。
2. **超爽快 3〜5ターン決着与ダメージ計算式**:
   - `baseDamage = self.atk * 2.5 * (100 / (100 + target.def * 0.35))`
   - 最低でも攻撃力の 50% は防御を貫通してダメージを与える最小保障を搭載。
   - 通常攻撃で 450〜650 ダメージ、必殺技で 900〜1300 ダメージを与え、3〜5ターンでスピーディーに決着。

## 4. 技術スタック

- **フロントエンド**: HTML5, Vanilla CSS3 (CSS Custom Properties / Glassmorphism)
- **スクリプト**: JavaScript (ES6+ Native Single Bundle `src/js/bundle.js`)
- **P2P通信ライブラリ**: PeerJS (WebRTC)
- **カメラ＆バーコード検出**: Web MediaDevices API, BarcodeDetector API

---

## 5. 品質・非機能要件

1. **キャッシュ無効化設計**: モバイルブラウザのスクリプトキャッシュ対策として `?v=2.1.0` クエリパラメーターと HTTP Meta ヘッダー (`no-cache`) を徹底適用。
2. **完全レスポンシブデザイン**: スマートフォン縦画面（360px〜430px）に最適化され、タッチ操作し易いタッチターゲット（最小高44px）を保証。
